# lovable-sites

Sites criados no Lovable. Cada pasta aponta para o repositório do site, que continua sincronizado com o Lovable.

| Pasta | Site | Repositório |
|---|---|---|
| [miguel-souza-advocacia](miguel-souza-advocacia) | Miguel Souza Advocacia (Pelotas/RS) | [rdgaz/pelotas-direito-em-conversa](https://github.com/rdgaz/pelotas-direito-em-conversa) |

Para atualizar as pastas com a versão mais recente de cada site:

```bash
git submodule update --remote
git commit -am "Atualiza sites"
git push
```
